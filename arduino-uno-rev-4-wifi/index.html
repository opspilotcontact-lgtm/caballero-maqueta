Descripción

El Arduino UNO R4 Wifi es la evolución de su hermano modelo R3, pero incluye además dos principales funcionalidades que lo hace brillar especialmente. Lo primero que debes saber es que en este modelo ha evolucionado desde el clásico microcontrolador de 8-bits a un potente procesador Renesas RA4M1 de 32-bits corriendo a 48MHz.

incluye en la misma placa un potente ESP32-S3 de Espressif que permite conectividad Wifi y Bluetooth.

Esto lo transforma automáticamente en la placa ideal para proyectos conectados que además necesiten de una capacidad de cálculo importante, porque además tiene una cantidad de memoria Flash y RAM ridículamente muy superior al modelo anterior.

Con esto podrás crear proyectos más grandes, más complejos y sin miedo a que la placa se te quede corta. ¿Recuerdas cuando tenías que sacar código y librerías porque no cogían en la placa? Con el Arduino UNO R4 Wifi eso se terminó.

Es probablemente la placa Arduino UNO más completa que se ha creado hasta ahora

Algunos de los puntos fuertes son:

Compatibilidad con hardware de Arduino UNO R3: El Arduino UNO R4 Wifi mantienen la misma forma y formato, pines, etc, así como el voltaje de funcionamiento de 5V. De esa forma es compatible con todas las shields y periféricos para el modelo R3.

Más memoria y más velocidad: Gracias un potente procesador de 32-bits y una velocidad de reloj de 48 MHz, podrás crear proyectos complejos como nunca antes, incluir muchas librerías, sin preocuparte de espacio libre de memoria.

Más periféricos integrados: El Arduino UNO R4 Wifi incluye un DAC de 12-bits, BUS CAN y un Op-Amp en la misma placa.

Alimentación máxima de 24 V: El Arudino UNO R4 Minma ahor soporta voltajes de alimentación de hasta 24V. Eso es ideal para entornos industriales sin que sufra la placa

Conexión Wi-Fi y Bluetooth: El Arduino UNO R4 Wifi tiene un módulo ESP32-S3 integrado. Puedes usarlo por tu cuenta o incluso conectarlo con Arduino IoT Cloudy monintorear en tiempo real los datos de tus proyectos.

Conector Qwiic: Arduino UNO R4 WiFi tiene un conector i2C Qwiic para conectar cientos de sensores y periféricos creados por Sparkfun y Adafruit entre otros, sin necesidad de soldar nada.

Soporte reloj RTC: El UNO R4 WiFi tiene un pin adicional "OFF" para apagar la placa y un pin "VRTC" para dejar el reloj RTC interno funcionando para conseguir consumos extremadamente bajos, así como interrupciones basadas en tiempo.

Matriz de LED integrada: El Arduino UNO R4 WiFi tiene una matriz de LED integrada de 12x8 diodos rojos, ideal para proyectos creativos o mostrar todo tipo de datos

Soporte HID: El Arduino UNO R4 Minima soporta de forma nativa USB HID y puede actuar como un periférico tal como ratón o teclado

Nuevo conector USB-C: Porque bueno, estamos en 2023 y una placa como esta se merece tener un conector como se debe.
