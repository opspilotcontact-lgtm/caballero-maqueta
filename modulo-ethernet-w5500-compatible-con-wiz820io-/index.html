Descripción

El módulo Ethernet WIZ850io es un módulo de tamaño compacto para placas Arduino y compatibles basado en el chip Wiznet W5500. Proporciona un modo sencillo de conectar tu módulo a la red local y a internet basado en Ethernet WIZNET con una interfaz TCP/IP. Compatible con librerías con la misma API Ethernet. Con este módulo con puerto RJ-45 se puede construir un servidor web. Puede ser usado como servidor o como cliente.

Características:

Módulo de Red de Plugin - Tamaño 23 x 25mm

Hardware compatible con WIZ820io.

Soporta hasta 8 conexiones de enchufe

Soporta el protocolo TCP, UDP, ICMP, IPv4, ARP, IGMP, PPPoE

La capa física de Ethernet 10BaseT/100BaseTX incorporada (PHY)

Apoyar la auto negociación (10/100-Based full dúplex / half dúplex)

Utilizable sin el diseño H/W para el W5500, el transformador y el RJ45.

Rápida evaluación para W5500 y MCU en la placa de destino.

Soporta la interfaz SPI de alta velocidad - 80MHz

Soporta el modo de apagado y la función Wake-on-LAN

Espacio de la cabeza 2.54mm

La pila de protocolos de hardware TCPIP incorporada

Capa de enlace de datos integrada, capa física

Apoyar el apagado del wakeup

Soporta la interfaz periférica serial de alta velocidad (modelo 0~3 SPI)

Buffer de recepción interno de 32K bytes

Aplicaciones:

El W5500 Lite es adecuado para las siguientes aplicaciones integradas:

Dispositivos de red doméstica: Set-Top Boxes, PVRs, Adaptadores de medios digitales

De serie a Ethernet: Controles de acceso, pantallas LED, relés AP inalámbricos, etc.

Paralelo-a-Ethernet: POS / Mini Impresoras, Copiadoras

USB a Ethernet: Dispositivos de almacenamiento, impresoras en red

GPIO-a-Ethernet: Sensores de la red doméstica

Sistemas de seguridad: DVRs, Cámaras de Red, Kioscos

Automatizaciones de fábricas y edificios

Equipo de monitoreo médico
