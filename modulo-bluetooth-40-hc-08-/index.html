Descripción

El Módulo Bluetooth HC-08 es un módulo electrónico de alta tecnología, desarrollado para enviar y recibir información vía Bluetooth (inalámbrico), siendo compatible con plataformas de prototipado Arduino, Raspberry PI, ARM, AVR, PIC, etc.

El Módulo Bluetooth HC-08 permite que el dispositivo envíe o reciba datos TTL a través de la tecnología Bluetooth sin tener que conectar un cable serial a la computadora. Es importante resaltar que este módulo permite la comunicación con los modelos de iPhone e iPad, a diferencia de los modelos HC-05 y HC-06.

En la práctica, el Módulo Bluetooth HC-08 se usa normalmente para crear redes inalámbricas, donde es posible crear redes para intercambiar información entre un Arduino y un teléfono inteligente, por ejemplo.

Al utilizar el Bluetooth HC-08 con equipos con sistemas IO, tendrá limitaciones específicas de la marca Apple, como la necesidad de una aplicación de reconocimiento y emparejamiento entre ellos, por lo que será necesario, en este caso, utilizar desde una aplicación. como JBWave.

A diferencia del HC-06, el módulo HC-08 puede funcionar en 2 modos diferentes: maestro (maestro) y esclavo (esclavo), mientras que el módulo Bluetooth HC-06 solo funciona en modo esclavo.

Cada uno de los 2 modos de uso del Módulo HC-08 tiene diferentes propósitos, el modo maestro se usa para conectarse a otros dispositivos, el modo esclavo solo se usa para recibir conexiones.

Cuando se usa junto con el Arduino, el HC-08 se presenta como uno de los módulos con mejor relación costo-beneficio, ya que es un producto de bajo costo y muy útil.

Nota: Es importante tener en cuenta que el Bluetooth HC-08 funciona con un nivel de señal de 3.3V, que no debe confundirse con la tensión de alimentación. Así, para usarlo con el Arduino es necesario usar un divisor de voltaje, ya que el Arduino tiene un nivel de señal de 5V.

Interfaz de comunicación: UART3.3VTTL nivel

Voltaje de funcionamiento: 2,0-3,6 v

Soporte RSSI: No compatible

Nivel de comunicación: 3,3 v

Potencia de transmisión: 4dBm (máx.)

Distancia de transmisión: 80 metros
