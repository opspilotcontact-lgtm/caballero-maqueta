Descripción

Es una tarjeta de desarrollo basada en ESP32 que incorpora un modulo LoRa 868/915 Mhz que permite transmitir de forma bidireccional datos a grandes distancias de igual incorpora un Display OLED de 128×64 píxeles (SSD1306 dirección I2C 0x3C) y cuanta con interfaz para carga de baterías litio.  Además, dispone de un conector microUSB para alimentación y programación directamente desde el IDE de Arduino o con Micropython.

¿Para que sirve TTGO LoRa32?

Esta tarjeta sirve para desarrollar sistemas enfocados al internet de las cosas “IOT” y para la transición de datos mediante Lora y así poder controlar sensores y actuadores, de igual manera esta diseñada para poder desplegar información al usuario mediante la Pantalla OLED que integra y así evitar el cableado que típicamente se realiza cuando se quiere integrar una display a sus proyectos.
