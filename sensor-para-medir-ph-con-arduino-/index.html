Descripción

El kit Sensor de pH para Arduino contiene todo lo necesario para realizar mediciones de potencial de hidrógeno de manera sumamente sencilla. ¿Buscas medir parámetros sobre la calidad del agua de forma sencilla, especialmente con Arduino? Este kit proporciona de forma instantánea la capacidad de realizar el monitoreo de pH a tu arduino con una precisión de +/- 0.1 pH en un rango de 0 a 14 unidades de pH.

Este producto es ideal para los proyectos de investigación  que requieren la recolección de datos y que muchos equipos comerciales no pueden proporcionar o son sumamente caros y difíciles de personalizar. Ahora puedes realizar tu propio medidor de pH con arduino, incluso con la capacidad para conectarse a la red (ya sea por ethernet o wifi) y registrar la información en un webservice o cualquier servicio de almacenamiento de datos en la nube, o bien conectar una memoria SD para registrar datos.

Con el Kit de sensor de pH para Arduino, las posibilidades son infinitas dada la flexibilidad de la plataforma arduino.
