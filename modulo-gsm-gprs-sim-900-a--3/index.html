Descripción

Características : GPRS clase 10/8 multi-slot. GPRS clase de estación móvil B. Compatible con GSM fase 2/2 + Clase 4 (2 W @ 850/900 MHz) Clase 1 (1 W @ 1800/1900 MHz) Pila (Stack) TCP/UDP incluida, permite conexión TCPIP de datos a un servidor web. Acepta conexión de Red RTC de telefonía conmutada. Permite seleccionar el puerto serie al que s econecta. Bajo consumo de energía en modo dereposo. Ideas de aplicación: M2M: Aplicaciones Machine 2 Machine. Control remoto de los aparatos. Estación Meteorológica remota o una Red de Sensores Inalámbricos. Sistema de Seguimiento de vehículos con un módulo GPS. Precauciones Asegúrese de que la tarjeta SIM está desbloqueada. La configuración por defecto de fábrica para el GPRS Shield UART es 19200 bps 8-N-1. (Se puede configurar mediante el el uso de comandos AT). Acepta alimentacion externa o a través de Arduino. Interfazde la antena, Conexión a antena externa. Serie Hardware-D0/D1 de Arduino. Software de serie-D7/D8de Arduino.
