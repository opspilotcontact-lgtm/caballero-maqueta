Descripción

Keyestudio 4WD Bluetooth Multi-functional Car es un sistema de desarrollo de aplicaciones de aprendizaje basado en microcontrolador y con ATmega-328 como núcleo.

Tiene funciones de seguimiento de línea, prevención de obstáculos, control remoto IR, control remoto Bluetooth y detección de distancia.

Este kit contiene muchos programas interesantes y puede ampliar un módulo de circuito externo para aumentar más funciones de este automóvil.

Tiene como objetivo desconectar a los usuarios de las teorías aburridas y obtener la capacidad de desarrollo del sistema cuando están aprendiendo Arduino.

Motor: Voltaje: 6-9V

Relación de reducción: 1:48

Elección del módulo de controlador L298N como motor de control, separado del microcontrollor

Tres módulos de seguimiento de línea, que tienen una mayor precisión al detectar líneas blancas y negras, capacesde realizar anti- caer

IR módulo de control remoto que componen un sistema de control remoto del coche módulo de ultrasonidos 5.Using para darse cuenta de evitación de obstáculos

Pairing teléfono móvil Bluetooth con el módulo de control remoto Bluetooth para controlar el coche
