Descripción

Este es un kit de aprendizaje robótico arduino potente y fácil de usar. Es adecuado para maker space, estudiantes universitarios y estudiantes de secundaria. La placa de control que se usa es el arduino UNO R3 y hay muchos tutoriales de aprendizaje en Internet lo que hace que sea más fácil de aprender y manejar

El método de control también es muy simple, con cuatro perillas para controlar el movimiento de cada potenciómetro, cualquiera puede operarlo. Después de conectar el ordenador al USB, puedes enviar comandos a través del puerto serie para controlar el movimiento del servo.

Al mismo tiempo, es compatible con otro software de control de  computadora y también admite programas de escritura usted mismo para realizar acciones fijas y repetitivas.

La dificultad estriba en el montaje de componentes acrílicos.
