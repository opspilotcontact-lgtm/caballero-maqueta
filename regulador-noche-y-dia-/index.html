Descripción

Regulador Día y Noche para belenes.

Mediante un conmutador podrá escoger entre la generacióndel efecto automático de anochecer, o el de amanecer.  Dispone de salidas de pulsador para encendido y apagado inmediato.

No admite cargas inductivas como lámparas PL, relés, fluorescentes, transformadores, etc.

Incorporabornes de conexión para facilitar el montaje.

Especialmente indicado para Belenes, teatros, modelismo, ambientaciones, etc.
