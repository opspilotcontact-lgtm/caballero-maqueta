Descripción

Es un shield comodo y que dispone de todo lo necesario.

Incorpora un lector/grabador de tarjetas SD y RTC, ademas de un regulador de 3.3V para alimentar el lector SD

Se puede guardar datos en archivos en cualquier tarjeta SD con formato FAT16 o FAT32, para ser leído posteriormente.

Permite leer todo tipo de archivos ya sea dibujos, Excel o analizar programas

Especificaciones técnicas:

Interface para de tarjetas SD: FAT 16 y FAT32.

Real Time Clock incluido basado en el RTC integrado 1307.

Porta pilas incluido para mantener la fecha durante años.

Regulador propio de 3.3V para alimentar la tarjeta SD.

Zona de prototipos para incluir tus sensores.

Alimentación: Pila CR1220

Dimensiones: 68 x 53 x 23 mm
